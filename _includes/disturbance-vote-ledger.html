Illustrative attribution vote How the selected cluster votes

First, the graph decides which records belong together. With the framework's default parameters, each link combines spatial decay, temporal decay, the mean reliability of the two sources, and a penalty for records from the same dataset.

Graph link e−distance / 300 m × e−delay / 180 days × mean reliability × (0.5 same source; 1 otherwise)

Louvain uses those link weights; HDBSCAN then refines each community from position, scaled time, and a cause-disagreement penalty. Only after that grouping does the vote below begin. Its weight is the reliability of each source, not the graph-link weight.

This schematic uses the documented vote weights, not a measured result. For the reference map, 0.70 is the source reliability and 0.30 is the deliberately reduced self-vote factor; the result is split between its two possible causes.
